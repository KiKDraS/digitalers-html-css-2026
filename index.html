Sass

Sass es un pre-procesador de CSS. Agrega funciones que CSS puro no tiene.

Conceptos Básicos

  • Variables: Guardan valores reutilizables (colores, tamaños, etc.).
  • Anidamiento (Nesting): Escribe reglas CSS dentro de otras, reflejando la estructura HTML.
  • Mixins: Funciones que reutilizan bloques de estilos.
  • Herencia (@extend): Comparte estilos entre selectores.
  • Módulos: Importa otros archivos Sass para reutilizar código.
    • @use — Recomendado. Importa un archivo como módulo con namespace (ej: u.$font). Usar siempre que necesites variables o mixins de otro archivo.
    • @forward — Re-exporta miembros de otros archivos. Usar en archivos índice (_index.scss) para agrupar exports.
  • Parciales: Archivos Sass que comienzan con _ (ej: _variables.scss) y no se compilan a CSS.

Componentes

Unidad reutilizable con estilos, HTML y funcionalidad.

CSS

  • Custom properties (variables CSS): Guardan valores reutilizables. Se definen con --nombre y se usan con var().
  • CSS Nesting: Técnica para escribir reglas CSS dentro de otras, reflejando la estructura HTML
  • Módulos (@import): Importa otros archivos CSS para reutilizar código.
  • Funciones: Operaciones predefinidas que procesan valores. Las más comunes
    • Matemáticas
      • calc
      • clamp
    • Colores
      • hsl
      • rgba
    • Transformación
      • rotate
      • scale
