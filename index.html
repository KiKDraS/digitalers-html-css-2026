¿Qué es una pseudo-clase?

Una pseudo-clase es una palabra clave que se añade a los selectores de CSS para especificar un estado especial del elemento seleccionado.

A diferencia de las clases comunes de HTML, las pseudo-clases permiten aplicar estilos basados en la interacción del usuario, el historial de navegación, la posición en el DOM o el estado de validación de un formulario, sin necesidad de añadir clases manuales o scripts de JavaScript.

Clasificación de pseudo-cases

🔹 Interacción y Acción

Se activan dinámicamente mediante el comportamiento del usuario con el dispositivo apuntador.

  • :hover - Cuando el cursor pasa por encima del elemento.
  • :active - En el momento exacto en que el elemento es presionado o cliqueado.

🔹 Estado y Foco

Cruciales para la accesibilidad; indican la posición actual del teclado o la navegación.

  • :focus - Cuando el elemento se selecciona (por ejemplo, mediante la tecla Tab).
  • :focus-visible - Aplica foco visual sólo si el navegador determina que ayuda a la navegación del usuario.

🔹 Formularios y Validación

Monitorean el estado de los datos introducidos en elementos de entrada.

  • :disabled - Elementos de formulario deshabilitados.
  • :checked - Elementos seleccionados (checkboxes o radio buttons).
  • :invalid - Entradas de datos que no cumplen con los requisitos de validación.

🔹 Estructurales (posición en el HTML)

Seleccionan elementos según su orden jerárquico dentro del HTML.

  • :first-child / :last-child - Primer o último hijo de un contenedor.
  • :nth-child(n) - Selecciona elementos utilizando patrones numéricos o fórmulas aritméticas (ej. pares o impares).
  • :first-of-type / :last-of-type - El primer o último elemento de su mismo tipo de etiqueta dentro de un contenedor.

🔹 Historial y Enlaces

Rastrean el estado de las URLs en la sesión de navegación.

  • :link - Enlaces que aún no han sido visitados.
  • :visited - Enlaces que el usuario ya ha cliqueado en el pasado.

Pseudo-clases Lógicas y Avanzadas

Estas herramientas modernas permiten agrupar selectores, manejar la especificidad y crear condicionales complejas de manera nativa.

:is() (El Agrupador con Absorción)

Reduce la redundancia al agrupar selectores en una sola línea. Toma la especificidad del selector más pesado dentro de sus argumentos.

/* Simplifica: h1, h2, h3 dentro de un article */
    article :is(h1, h2, h3) {
      margin-bottom: 1rem;
    }

:where() (El Selector de Peso Cero)

Funciona exactamente igual que :is(), pero su especificidad es **siempre cero (0,0,0,0)**, lo que lo hace perfecto para resets o sistemas de diseño altamente sobreescribibles. 

/* Estilos base fáciles de pisar más adelante */
    :where(.card, .sidebar) p {
      color: gray;
    }

:has() (El Selector Relacional o "Padre")

Permite aplicar estilos a un elemento contenedor basándose en lo que ocurre con sus hijos o hermanos. Es una de las funciones más potentes agregadas al CSS moderno.

/* Aplica estilos a la .card SOLO si contiene una imagen dentro */
    .card:has(img) {
      padding: 0;
      border-radius: 8px;
    }

Pseudo-elementos (::)

¿Qué es un pseudo-elemento? A diferencia de las pseudo-clases (que manejan estados como :hover), un pseudo-elemento sirve para crear u organizar partes específicas de un elemento o inyectar contenido virtual en la ventana desde CSS sin tocar el HTML.

  • ::first-letter - Primera letra de un párrafo.
  • ::first-line - Primera línea de un párrafo.
  • ::selection - Texto seleccionado.
  • ::before/::after - Añaden contenido antes/después del elemento.

1. ::before y ::after

Permiten inyectar contenido decorativo antes o después del contenido real de un elemento. Es obligatorio usar la propiedad content.

.alerta::before { content: "⚠️ ATENCIÓN: "; color: red; }
.link-externo::after { content: " ↗"; }

Este es un mensaje de error crítico en la interfaz.

Puedes leer más documentación en este enlace externo.

2. ::placeholder

Permite darle estilos específicos al texto de sugerencia temporal que va dentro de los elementos de formulario como <input> o <textarea>.

input::placeholder { color: #a0aec0; font-style: italic; }

3. ::selection

Controla los estilos de cualquier texto o elemento en el momento exacto en el que el usuario lo selecciona arrastrando el cursor del ratón o manteniendo presionado en pantallas táctiles.

p::selection { background-color: #ffe066; color: #000; }

¡Pruébame! Selecciona este bloque de texto con tu mouse o tu dedo y verás cómo cambia el color de fondo del resaltado por defecto azul del navegador a uno amarillo personalizado.

4. ::first-letter y ::first-line

Selectores de diseño editorial. ::first-letter apunta a la letra capital (la primera del párrafo) y ::first-line aplica estilos exclusivamente a la primera línea renderizada en pantalla.

p::first-letter { font-size: 3.5rem; float: left; color: blue; }
p::first-line { font-weight: bold; }

Este párrafo simula el comienzo de una nota periodística o artículo de blog de alta calidad visual. Si cambias el tamaño de la ventana del navegador, verás que la primera línea mantiene su estilo en negrita de forma dinámica sin importar qué palabras se reacomoden.

5. ::marker

Permite seleccionar y modificar de forma directa la viñeta (el punto o número) de los elementos de una lista sin tener que ocultarlos con trucos complejos.

li::marker { content: "⚡ "; font-size: 1.2rem; }
  • Primer requerimiento del sistema de desarrollo.
  • Segundo requerimiento totalmente responsivo.
  • Validaciones de accesibilidad web (WCAG) completadas.

::marker vs ::before

  • ::marker (Nativo): Modifica directamente la viñeta que el navegador ya calculó. Es ultra eficiente, pero altamente limitado. Solo acepta propiedades de fuente, color y contenido (no permite layouts, márgenes, fondos complejos ni sombras).
  • ::before (Custom): Requiere apagar la viñeta nativa con list-style: none y simular una nueva. Es más laborioso, pero te otorga **el 100% de las propiedades de CSS** (flexbox, degradados, sombras, tamaños fijos en px, etc.). 
/* Código utilizado en la comparativa de abajo */
    .enfoque-marker li::marker {
      content: "🔥";
    }
    
    .enfoque-before {
      list-style: none;
      li {
        display: flex; gap: 12px;
        &::before {
          content: ""; width: 10px; height: 10px;
          background: linear-gradient(135deg, #535bf2, #9c27b0);
          border-radius: 50%; box-shadow: 0 3px 6px rgba(0,0,0,0.2);
        }
      }
    }
  • Usa la caja nativa de la viñeta.
  • Alineación automática del navegador.
  • Limitado a texto o emojis planos.
  • Viñeta hecha a mano (Caja virtual).
  • Control total con Flexbox y gaps.
  • Soporta sombras, bordes y degradados.
