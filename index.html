Position

La propiedad position controla cómo se coloca un elemento en la página. Tiene 5 valores principales:

  • static — (valor por defecto): el elemento sigue el flujo normal de la página.
  • relative — se mueve respecto a su posición original (con top, left, etc.).
  • absolute — se posiciona respecto a su ancestro más cercano con position (no static). Si no encuentra ninguno, se ubica en relación al body.
  • fixed — se queda fijo en la pantalla (útil para menús que no se mueven al hacer scroll).
  • sticky — híbrido entre relative y fixed ("se pega" al hacer scroll).

1. Static — Estático

Es el valor por defecto. El elemento se coloca según el flujo normal de la página, uno debajo del otro. Las propiedades top, left, right y bottom no tienen ningún efecto.

Static
.static {
    /* position: static; — es el valor por defecto */
    /* top, left, right, bottom no funcionan aquí */
}

2. Relative — Relativo

El elemento se mueve respecto a su posición original. Usa top, left, right y bottom para desplazarlo. El espacio que ocupaba originalmente se reserva (los elementos de alrededor no se reacomodan).

Relative (top: 8px)
.relative {
    position: relative;
    top: 8px;    /* se desplaza 8px hacia abajo */
    left: 0;     /* podés usar left, right, bottom */
}

3. Absolute — Absoluto

El elemento sale del flujo normal (los demás elementos lo ignoran) y se posiciona respecto a su ancestro más cercano que tenga position: relative, absolute, fixed o sticky.

En este ejemplo, el cuadro chocolate está adentro de un contenedor con position: relative, por eso se ubica en la esquina inferior derecha de ese contenedor:

Absolute
.relative-2 {
    position: relative;  /* este contenedor es el ancla */
    width: 95vw;
    max-width: 550px;
    height: 35vh;
    max-height: 500px;
    border: 1px solid black;
}

.absolute {
    position: absolute;
    bottom: 0;   /* pegado al borde inferior */
    right: 0;    /* pegado al borde derecho */
}

⚠️ Cuidado: Si ningún ancestro tiene position declarado, el elemento absolute se "escapa" y se posiciona respecto al <body>. El cuadro con la clase "absolute-no-reference", no tiene un contenedor con position (no static) como padre y por eso se fue al body:

¡Estoy perdido! 😱
/* Sin un ancestro con position (no
                    static), este cuadro
   se posiciona respecto al <body> */
.absolute-no-reference {
    position: absolute;
    top: 0;      /* se pega al borde superior del body */
    right: 0;    /* se pega al borde derecho del body */
}

📌 z-index: superposición de capas

Cuando dos elementos se superponen, z-index controla quién queda arriba. Es como una pila de capas: mayor valor = más arriba. Solo funciona si el elemento tiene position distinto de static.

Absolute (z-index: 2)
Absolute 2 (z-index: 3)
Absolute 3 (z-index: 1)
.absolute  { z-index: 2; }
.absolute-2 { z-index: 3; }  /* ← este queda arriba */
.absolute-3 { z-index: 1; }  /* ← este queda abajo */

4. Fixed — Fijo

El elemento sale del flujo normal y se queda fijo en la ventana del navegador. No importa si hacés scroll hacia arriba o abajo — el elemento siempre se ve en la misma posición de la pantalla.

📌 Usos comunes: menús de navegación fijos, botones flotantes, banners de cookies.

Fixed
.fixed {
    position: fixed;
    bottom: 0;   /* pegado al borde inferior */
    right: 0;    /* pegado al borde derecho */
}

5. Sticky — Pegajoso

Es un híbrido entre relative y fixed: se comporta como relative hasta que el scroll alcanza un límite (definido con top, left, etc.), y en ese momento se "pega" y se comporta como fixed. 

nav {
    position: sticky;
    top: 0;   /* cuando el scroll llega a 0, se "pega" arriba */
    left: 0;
    background-color: rgba(0, 0, 0, 0.8);
}
Position: Sticky

📌 ¿Por qué sticky parece no funcionar a veces?

1. El contenedor padre es el que manda.
position: sticky solo funciona dentro de los límites de su contenedor padre. El elemento se "pega" cuando llega al top indicado, pero deja de pegarse cuando el borde inferior del padre está a punto de pasarlo. Es decir: el padre actúa como un "carril" que limita hasta dónde puede moverse el elemento sticky.

⚠️ El <nav> de esta página NO funciona como sticky. ¿Por qué? Porque está dentro del <header>. El contenedor padre del nav es el header, y el header ocupa solo una parte de la pantalla. Apenas el header sale de la ventana al hacer scroll, el nav se va con él — el sticky se "despega" porque el carril del padre se terminó.

Para que funcione, el <nav> debería ser hijo directo del <body> (o de un contenedor que abarque toda la altura del viewport). Así el carril del sticky sería toda la página y el nav se mantendría pegado arriba mientras scrolleás el contenido.

2. Compatibilidad con display: flex y display: grid.
Cuando un contenedor usa display: flex o display: grid, el comportamiento sticky puede fallar o comportarse distinto por dos razones:

  • El contenedor padre es el que define el área de scroll. En un flex o grid container, el sticky se pega dentro del área del ítem, no del contenedor entero. Si el contenedor flex/grid tiene overflow: hidden o una altura fija, el sticky queda limitado a ese espacio.
  • El valor de align-self o justify-self puede interferir. En flexbox, por defecto los hijos se estiran (align-self: stretch), y un elemento sticky no puede pegarse correctamente si su altura es igual a la del contenedor (no tiene espacio para scroll). Solución: usar align-self: flex-start para que el elemento tenga su altura natural y pueda desplazarse. 
/* ❌ Sticky no funciona bien en flex si el hijo se estira */
.flex-container {
    display: flex;

    .child {
        position: sticky;
        top: 0;
        /* align-self: stretch (por defecto) → sin espacio para scrollear */
    }
}

/* ✅ Solución: darle altura natural al hijo sticky */
.flex-container nav {
    display: flex;

    .child {
        position: sticky;
        top: 0;
        align-self: flex-start;  /* o height: auto */
    }
}

Degradados en CSS

Los degradados (gradients) permiten crear transiciones suaves entre dos o más colores directamente desde CSS. Son ideales para fondos, botones, tarjetas y más — sin necesidad de imágenes.

  • lineal — el color cambia en una dirección recta (horizontal, vertical, diagonal).
  • radial — el color se expande desde un punto central, como un círculo o elipse.
  • cónico — los colores giran alrededor de un punto, como una rueda cromática.
  • repetitivo — el patrón del degradado se repite una y otra vez.

1. linear-gradient() — Degradado lineal

El degradado más común. Los colores se distribuyen en una línea recta. Podés controlar la dirección con palabras clave (to right, to bottom, etc.) o con ángulos (45deg, 135deg).

📐 ¿Cómo funcionan los ángulos?

El ángulo indica la dirección de la línea del degradado. El primer color se ubica al inicio de esa línea y el último al final.

Los ángulos en CSS crecen en sentido horario (como las agujas del reloj), empezando desde arriba:

             
            ↑ 0deg (to top)
            │
270deg ←────┼────→ 90deg
(to left)   │      (to right)
            ↓
        180deg (to bottom)

Para que sea más fácil, acá están todas las equivalencias:

Ángulo Keyword Inicio → Final
0deg to top abajo → arriba
45deg to top right inf-izquierda → sup-derecha
90deg to right izquierda → derecha
135deg to bottom right sup-izquierda → inf-derecha
180deg to bottom arriba → abajo
225deg to bottom left sup-derecha → inf-izquierda
270deg to left derecha → izquierda
315deg to top left inf-derecha → sup-izquierda

⚠️ Importante: En matemática, 0° apunta a la derecha y los ángulos crecen en sentido anti-horario. En CSS, 0deg apunta arriba y crece en sentido horario (como un reloj).
45deg y to top right producen exactamente el mismo resultado — veamos:

→ Horizontal

.gradient-linear-horizontal {
    background: linear-gradient(to right, #ff7e5f, #feb47b);
}

→ Diagonal (135deg)

.gradient-linear-diagonal {
    background: linear-gradient(135deg, #667eea, #764ba2);
    /* 135deg = to bottom right = sup-izquierda → inf-derecha */
}

→ Múltiples colores (arcoíris)

.gradient-linear-multicolor {
    background: linear-gradient(to right,
        red, orange, yellow, green,
        blue, indigo, violet);
}

2. radial-gradient() — Degradado radial

El color se expande desde un punto central hacia afuera. Podés elegir entre forma circular o elíptica, y controlar el tamaño con palabras clave como closest-side o farthest-corner.

→ Circular

.gradient-radial-circle {
    background: radial-gradient(circle, #f9d423, #ff4e50);
}

→ Elíptica

.gradient-radial-ellipse {
    background: radial-gradient(ellipse at center, #a8edea, #fed6e3);
}

→ control de tamaño: closest-side

.gradient-radial-closest {
    background: radial-gradient(
        closest-side at 30% 50%,
        #ff7e5f, #feb47b, #667eea
    );
}

💡 Dato: closest-side mide el gradiente hasta el lado más cercano del contenedor. farthest-corner (valor por defecto) lo mide hasta la esquina más lejana. Esto cambia cómo se ve el degradado según el tamaño del contenedor.

3. conic-gradient() — Degradado cónico

Los colores giran alrededor de un punto central, como si fuera una rueda cromática. Se usa mucho para hacer gráficos de torta, ruedas de colores y efectos circulares.

→ Rueda de colores

.gradient-conic {
    background: conic-gradient(
        red, yellow, lime, aqua,
        blue, magenta, red
    );
    border-radius: 50%;
}

→ Con paradas de color específicas

.gradient-conic-simple {
    background: conic-gradient(
        from 0deg,
        #ff7e5f 0deg,
        #feb47b 90deg,
        #667eea 180deg,
        #764ba2 270deg,
        #ff7e5f 360deg
    );
    border-radius: 50%;
}

4. repeating-* — Degradados repetitivos

¿Y si el degradado se repite en lugar de estirarse? Con repeating-linear-gradient() y repeating-radial-gradient() podés crear patrones tipo cebra, rayas, cuadros y más.

→ Patrón diagonal tipo cebra

.gradient-repeating {
    background: repeating-linear-gradient(
        45deg,
        #ff7e5f 0px, #ff7e5f 10px,
        #feb47b 10px, #feb47b 20px
    );
}

→ Franjas de colores

.gradient-repeating-rainbow {
    background: repeating-linear-gradient(
        to right,
        red 0px, red 20px,
        orange 20px, orange 40px,
        yellow 40px, yellow 60px  /* ... */
    );
}

⚠️ Cuidado: La clave de los degradados repetitivos está en las paradas de color. Cada color debe terminar donde empieza el siguiente para que el patrón sea continuo. Si hay espacios, verás transiciones en lugar de cortes definidos.

6. Combinar degradados (capas)

Podés apilar varios degradados separándolos con coma. El primero queda arriba, el último abajo. Esto permite crear efectos complejos con transparencia. 

.gradient-multiple {
    background:
        /* Capa superior: degradado semitransparente */
        linear-gradient(
            135deg,
            rgba(102, 126, 234, 0.6),
            rgba(118, 75, 162, 0.6)
        ),
        /* Capa inferior: patrón repetitivo */
        repeating-linear-gradient(
            45deg,
            #ff7e5f 0px, #ff7e5f 5px,
            #feb47b 5px, #feb47b 10px
        );
}

💡 Dato: Los degradados con rgba() o hsla() combinados con opacidad permiten que las capas de abajo se vean a través de las de arriba. Es una técnica muy usada para crear texturas visuales sin imágenes.

7. Herramientas útiles para crear degradados

Estos sitios te ayudan a visualizar y generar degradados sin escribir código desde cero:

  • cssgradient.io — Generador simple con previsualización en vivo. Ideal para crear degradados lineales y radiales y copiar el CSS al instante.
  • uigradients.com — Colección de degradados pre-diseñados. Perfecto para inspirarse y ver combinaciones de colores que funcionan bien juntos.
