CSS

CSS (Cascading Style Sheets) es un lenguaje de selectores pensado para dar estilos a los elementos de nuestro HTML

Selectores

  • Simples
    • ID - Modificamos el elemento cuyo atributo id corresponda con el selector (#id)
    • Clase - Modificamos el/los elemento/s cuyo atributo class corresponda con el selector (.class)
    • Elemento - Modificamos los elementos cuyo nombre corresponda con el selector (nombre-de-etiqueta)
    • Selector Universal (*) - Permite modificar todos los elementos HTML
  • Compuestos - Se crea utilizando selectores simples y/u otros selectores compuestos
    • Grupal - Permite aplicar el mismo valor a la misma propiedad en varios selectores

Reglas de Trabajo

  • Herencia - Los elementos reciben los estilos aplicados a su contenedor padre
  • Importancia - Los elementos reciben los estilos aplicados a su contenedor padre más cercano
  • Especificidad - Valor arbitrario utilizado por CSS para resolver conflictos
    • Cuantos menos elementos modifique el selector, más su valor de especificidad
  • * Orden de lectura
    • Solo aplica si la especificidad es la misma
    • Se aplica el último estilo leído

Tipo de Elemento

Cuando hacemos CSS, tenemos que pensar a los elementos del HTML como si fueran cajas (Box Model)

Cuando trabajamos con CSS, podemos definir características de caja. Los navegadores, aplican estilos CSS por defecto. Es posible hablar de Tipos de Elemento

Los Tipos de Elemento son una serie de reglas de CSS que le otorgan características a la caja

  • Elemento de Bloque
    • Ocupa el 100% del ancho de su contenedor. Sin importar el tamaño del contenido
    • Fuerza un salto de línea
    • Se le puede modificar ancho(width) y alto(height)
  • Elemento de Línea
    • Ocupan sólo el tamaño de su contenido
    • No fuerzan salto de línea
    • No se puede modificar width ni height
  • Elemento de Línea-Bloque
    • Ocupan sólo el tamaño de su contenido
    • No fuerzan salto de línea
    • Se le puede modificar ancho(width) y alto(height)

Tipo de Unidades de Medida

Herramienta que el navegador utiliza para sacar la cuenta del tamaño que una propiedad debe tener

  • Absolutas - Con las absolutas, el navegador aplica una igualdad
    • px - width: 150px; -> La propiedad width es 150px
  • Relativas - Con las relativas, el navegador aplica una ecuación
    • Porcentaje(%) - tamaño = (ancho/alto del contenedor padre * %)px
    • em
    • rem
    • Viewport
      • vw | vh
      • dvw | dvh

Imágenes

Formularios

En HTML, un formulario es una herramienta que permite recolectar datos. En HTML solo recolectamos los datos.

  • ¿Qué datos necesito? - HTML y qué etiquetas y atributos voy a utilizar
  • ¿Qué quiero hacer con esos datos? - Lenguajes de Programación (PHP, JS, etc) y cómo voy a usar esos datos
