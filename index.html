HTML

Hypertext Markup Language (Lenguaje de Marcado de Hipertexto). Creado en 1993 y mantenido por la W3C (World Wide Web Consortium) y WHATWG (Web Hypertext Application Technology Working Group)

Etiquetas Semánticas

Son etiquetas contenedoras que permiten ordenar el código HTML

Imprescindibles

  • header - Contiene todo lo relacionado a la identidad de la página y la identidad del usuario conectado (si existe la posibilidad de hacer login)
  • nav - Contiene elementos de navegación. En HTML, un elemento de navegación se representa con la etiqueta a. No todo elemento a genera una "barra de navegación"
  • main - Contiene todo lo relacionado con el contenido de la página. NO DEBE HABER MÁS DE UN MAIN VISIBLE EN UN DOCUMENTO HTML
  • footer - Contiene toda la información legal de la página

Ocasionales

  • section - Representa una sección del contenido principal. No puede haber section sin etiqueta h(2-6)
  • article - Representa contenido adicional que puede ser entendido fuera del contexto de mi sitio web
    • Noticias de las páginas de diarios de noticia
    • Post de los blogs
    • Tarjetas de producto
  • aside - Permite agregar contenido relacionado al contenido principal, pero que puede no estar
  • figure - Permite vincular una imagen con un texto usando figcaption

Rutas

  • Relativas - Se arman en relación al root del proyecto. Se usan solo para trabajar con elementos que se encuentran dentro del proyecto
