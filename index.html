Diseño Responsivo

Es un enfoque de diseño web que busca crear sitios web que se adapten a diferentes tamaños de pantalla y dispositivos, como computadoras de escritorio, tabletas y teléfonos móviles.

Más info

Mobile First

Es una estrategia de diseño que prioriza la creación de experiencias óptimas para dispositivos móviles antes de adaptarse a pantallas más grandes. En lugar de diseñar primero para computadoras de escritorio y luego ajustar el diseño para dispositivos móviles, se comienza con un diseño simple y funcional para móviles, y luego se expande a pantallas más grandes.

Breakpoint

Una medida que se utiliza para decirle al navegador que tiene que cambiar el layout (disposición) de los elementos. Se utilizan para indicar cómo queremos que se vea nuestra web en un dispositivo mobile, una tablet o un monitor de pc

Breakpoints más comunes

  • hasta 768px - celulares y tablets pequeñas
  • hasta 900px - tablets
  • desde 1200px - monitores

Custom Properties (variables de CSS)

Son una herramienta que permite crear cajas que guardan un valor que se va a reutilizar a largo de todo el proyecto. Son útiles para mantener la consistencia en el diseño y facilitar los cambios globales.

Utility class

Una clase de CSS pensada no para un elemento en particular sino para aplicar una serie de propiedades a varios elementos

Colores

  1. HEX (Hexadecimal): El formato compacto

    Es el sistema más tradicional en la web. Utiliza un código de 6 caracteres precedido por un hash (#).

    Cómo funciona:

    Es un sistema de base 16 (números del 0 al 9 y letras de la A a la F). Se divide en tres pares estrictos: #RRGGBB (Rojo, Verde, Azul).

    • 00 significa apagado total.
    • FF significa intensidad máxima.
    Ejemplo en CSS:
    color: #ff0000; /* Rojo puro */

    Para qué sirve en Frontend:

    Es ideal para copiar y pegar rápidamente desde herramientas de diseño como Figma. Ocupa muy poco espacio en tu archivo CSS.

  2. RGB (Red, Green, Blue): La mezcla de luz

    Este formato representa el color de forma aditiva, tal como lo hace el hardware del monitor combinando bombillas de luz roja, verde y azul.

    Cómo funciona:

    Utiliza una función matemática rgb(R, G, B) donde pasas tres valores separados por comas (o espacios en CSS moderno). Cada valor va del 0 (apagado) al 255 (intensidad máxima).

    Ejemplo en CSS:
    color: rgb(255, 0, 0); /* Rojo puro */

    Para qué sirve en Frontend:

    Es mucho más legible para un programador que el código HEX. Si ves rgb(250, 250, 250), sabes instantáneamente que es casi blanco porque los tres canales de luz están casi al máximo.

  3. RGBA: El RGB con canales de transparencia

    Es exactamente igual al RGB tradicional, pero añade un cuarto elemento: el Canal Alfa (Alpha channel), que controla la opacidad.

    Cómo funciona:

    El cuarto valor es un número decimal que va del 0.0 (completamente transparente/invisible) al 1.0 (completamente opaco).

    Nota de CSS moderno: Hoy en día ya no es obligatorio escribir rgba(). La función estándar rgb() ya acepta la opacidad usando una barra diagonal: rgb(255 0 0 / 0.5).

    Ejemplo en CSS:
    background-color: rgba(0, 0, 0, 0.5);

    Para qué sirve en Frontend:

    Es el rey absoluto cuando necesitas crear efectos de capas, como un fondo oscuro difuminado detrás de un modal (overlay) o texturas sutiles.

  4. HSL (Hue, Saturation, Lightness): El formato humano

    Este formato es el más querido por los desarrolladores que buscan programar de forma inteligente. En lugar de pensar en "luz mezclada", piensa en cómo los humanos percibimos el color.

    Cómo funciona:

    Utiliza la función hsl(H, S, L) con tres valores muy lógicos:

    • Hue (Tono): Se mide en grados (0 a 360) como una rueda de colores. El 0 es rojo, el 120 es verde, el 240 es azul.
    • Saturation (Saturación): Se mide en porcentaje. 0% es gris grisáceo (sin color) y 100% es el color en su máxima viveza.
    • Lightness (Luminosidad): Se mide en porcentaje. 0% es negro absoluto, 100% es blanco absoluto, y 50% es el color puro.
    Ejemplo en CSS:
    color: hsl(0, 100%, 50%);
