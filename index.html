Git / GitHub

¿Qué es Git?

Git es un sistema de control de versiones distribuido y de código abierto, diseñado para manejar todo, desde proyectos pequeños hasta grandes con velocidad y eficiencia. Fue creado por Linus Torvalds en 2005 para desarrollar el kernel de Linux. Las principales características de Git incluyen:

  • Ramas (branches) - Permiten trabajar en diferentes versiones de un proyecto simultáneamente.
  • Commits - Guardan cambios en el repositorio, permitiendo rastrear y revertir cambios.
  • Repositorio (repository) - Es el lugar donde se almacena el historial completo de cambios de un proyecto.
  • Fusión (merge) - Combina diferentes ramas en una sola.

¿Qué es GitHub?

GitHub (hosting de código) es una plataforma de desarrollo colaborativo que utiliza Git para el control de versiones. Además, ofrece herramientas para facilitar la colaboración entre desarrolladores, como:

  • Repositorios remotos - Almacenan el código en la nube, accesible para múltiples usuarios.
  • Issues y Pull Requests - Facilitan la colaboración y revisión de código.
  • Integración Continua - Permite automatizar pruebas y despliegues.
  • Comunidades y Equipos - Fomenta la colaboración entre desarrolladores a través de organizaciones y equipos.

¿Cómo funciona GitHub Pages?

GitHub Pages es un servicio de GitHub que permite alojar sitios web estáticos directamente desde un repositorio de GitHub. Es ideal para alojar páginas personales, blogs, o sitios web de proyectos. Funciona de la siguiente manera:

  1. Repositorio: Crea un repositorio en GitHub.
  2. Contenido: Añade archivos HTML, CSS, y JavaScript al repositorio.
  3. Configuración: En las opciones del repositorio, habilita GitHub Pages.
  4. Despliegue: GitHub Pages generará automáticamente una URL donde estará alojado tu sitio web (por ejemplo, https://tuusuario.github.io/turepositorio).
  5. Actualizaciones: Cada vez que hagas un push a la rama configurada para GitHub Pages (main o gh-pages), el sitio se actualizará automáticamente.

Reglas de trabajo

  • Herencia - Los elementos reciben los estilos aplicados a su contenedor padre
  • Importancia - Los elementos reciben los estilos aplicados a su contenedor padre más cercano
  • Especificidad - Valor arbitrario utilizado por CSS para resolver conflictos
  • * Orden de lectura
    • Solo aplica si la especificidad es la misma
    • Se aplica el último estilo leído

Selectores

  • Básicos
    • ID - Modificamos el elemento cuyo atributo id corresponda con el selector (#id)
    • Clase - Modificamos el/los elemento/s cuyo atributo class corresponda con el selector (.class)
    • Elemento - Modificamos los elementos cuyo nombre corresponda con el selector (nombre-de-etiqueta)
    • Selector Universal (*) - Permite modificar todos los elementos HTML
  • Compuestos - Calculan su valor de especificidad sumando los valores de los selectores que los componen
    • Grupal - Permite aplicar el mismo valor a la misma propiedad en varios selectores
    • Selector descendente
      • Selector de hijo - Un elemento dentro de otro. Sin importar la profundidad del árbol genealógico
      • Selector de hijo directo - Un elemento dentro de otro. Solo debe haber un rango de profundidad en el árbol genealógico

CSS Nesting

El CSS Nesting es una característica moderna que permite escribir reglas de estilo unas dentro de otras, imitando la misma estructura jerárquica y visual que tiene tu propio código HTML.

Características

  1. Especificidad - Mientras el selector de referencia (padre del elemento a modificar) sea simple, el cálculo de especificidad no se ve modificado
  2. Soporte - El CSS Nesting fue oficialmente soportado por todos los navegadores en el año 2023. No funciona con versiones de navegadores anteriores. Podemos saber más sobre esto utilizando caniuse.com
