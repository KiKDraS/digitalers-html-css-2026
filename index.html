Clase 01

HTML

HTML es el lenguaje que permite estructurar el contenido de la página. Comunicación con el navegador

  • Valor semántico de la etiqueta: Información que el navegador recibe para entender cuál es el contenido

CSS (Cascading Style Sheets - Hojas de estilo en cascada)

CSS permite modificar la visual. Comunicación con el usuario

Tres formas de agregar CSS

  • CSS inline - Agrear un atributo (style) a la etiqueta para indicar los estilos CSS
  • CSS interno - Utilizar la etiqueta style para agregar estilos CSS dentro del documento HTML.
    • Se agrega dentro del head
    • El contenido es código CSS
    • No es común el uso de los estilos internos. Pero puede ser relevante en casos específicos
  • CSS externo - Agregar archivos de CSS y vincularlos a nuestro documento HTML

Tipos de Ruta

Elemento que utilizamos para indicar al navegador dónde encontrar el archivo que necesitamos

  • Relativas - /styles/index.css - Tienen el camino ACORTADO que el navegador tiene que hacer para llegar hasta el elemento que necesitamos. Se utilizan para trabajar con elementos de nuestro proyecto
    • No pueden llevar a elementos fuera del proyecto
    • El navegador arranca su camino desde mi proyecto (root)
      1. ¿Cuál es el archivo en el que voy a crear la ruta? - index.html
      2. En relación al root del proyecto. ¿Dónde se encuentra el archivo en el que voy a escribir la ruta? - El index.html se encuentra en el root del proyecto
      3. ¿A qué archivo queremos ir? - index.css
      4. En relación al root del proyecto. ¿Dónde se encuentra el archivo al que quiero llegar? - El archivo index.css se encuentra en la carpeta styles. La carpeta styles se encuentra en el root
  • Absolutas - https://www.google.com - Tienen todo el camino completo que el navegador debe hacer para llegar al objetivo. Se utilizan para trabajar con elementos que no se encuentran en nuestro proyecto (elementos que están en internet)
