CSS

Reglas de trabajo

  • Herencia - Los elementos reciben los estilos aplicados a su contenedor padre
  • Importancia - Los elementos reciben los estilos aplicados a su contenedor padre más cercano
  • Especificidad - Valor arbitrario utilizado por CSS para resolver conflictos
  • * Orden de lectura
    • Solo aplica si la especificidad es la misma
    • Se aplica el último estilo leído

Selectores

  • Básicos
    • ID - Modificamos el elemento cuyo atributo id corresponda con el selector (#id)
    • Clase - Modificamos el/los elemento/s cuyo atributo class corresponda con el selector (.class)
    • Elemento - Modificamos los elementos cuyo nombre corresponda con el selector (nombre-de-etiqueta)
    • Selector Universal (*) - Permite modificar todos los elementos HTML
  • Compuestos - Calculan su valor de especificidad sumando los valores de los selectores que los componen
    • Grupal - Permite aplicar el mismo valor a la misma propiedad en varios selectores
    • Selector descendente
      • Selector de hijo - Un elemento dentro de otro. Sin importar la profundidad del árbol genealógico
      • Selector de hijo directo - Un elemento dentro de otro. Solo debe haber un rango de profundidad en el árbol genealógico

Especificidad de los selectores

La Especificidad de un Selector es un cálculo que el navegador hace para saber qué estilo aplicar cuando hay un conflicto. Siempre se aplica el estilo declarado con el Selector de valor más alto

CSS Nesting

El CSS Nesting es una característica moderna que permite escribir reglas de estilo unas dentro de otras, imitando la misma estructura jerárquica y visual que tiene tu propio código HTML.

Características

  1. Especificidad - Mientras el selector de referencia (padre del elemento a modificar) sea simple, el cálculo de especificidad no se ve modificado
  2. Soporte - El CSS Nesting fue oficialmente soportado por todos los navegadores en el año 2023. No funciona con versiones de navegadores anteriores. Podemos saber más sobre esto utilizando caniuse.com

Box Modeling

En CSS, el Box Modeling es una forma de pensar la estructura para realizar los diseños basada en cajas

las propiedades de box modeling no se heredan

  • Propiedades de la caja (cómo se forma la caja)

    • width
    • height
    • border
    • margin
    • padding

  • Forma en que se calcula el espacio ocupado por la caja

    • content-box (por defecto): El espacio final ocupado por la caja es el resultado de la suma de su contenido, width, padding, margin y border
    • border-box: El espacio final ocupado por la caja es igual al width/height. Se reduce el espacio del contenido

  • Características de la caja (tipo de display)

    • Elemento de línea (display: inline)
    • Elemento de bloque (display: block)
    • Elemento de línea-bloque (display: inline-block)
    • Display de "control de posición" - Se utilizan para modificar el layout de los elementos contenidos
      • Elementos flexibles (display: flex)
      • Elementos de grilla (display: grid)

Unidades de Medida

Son la herramienta que el navegador utiliza para calcular el tamaño que los distintos elementos deben tener

  • Absolutas - El tamaño es igual a la Medida
    • px
  • Relativas - El tamaño es el resultado del cálculo correspondiente a la medida utilizada
    • % - tamaño = ancho/alto del contenedor padre * %. Tamaño se calcula en relación al contenedor padre
    • vw/vh - tamaño = ancho(vw)/alto(vh) de la ventana del navegador. Tamaño se calcula en relación al navegador

        Unidades variables de viewport
      • svw - ancho más chico del viewport
      • lvw - ancho más largo del viewport
      • dvw - ancho dinámico del viewport
    • em - tamaño = alto de la tipografía del elemento actual * em. Tamaño depende de la tipografía del elemento actual. Tener presente que la propiedad font-size es heredable
    • rem - tamaño = alto de la tipografía del root (navegador). Tamaño depende de la tipografía del navegador

Se recomienda % para contenedores internos y viewport para contenedores externos.
